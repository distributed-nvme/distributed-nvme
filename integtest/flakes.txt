# integtest/flakes.txt — the flake record (layout.md, Directory tree): one
# entry per Go test or suite stage that fails now and then, so that a failure
# of one of them is read as what it is before it is read as a regression of
# the change under test. A text file, not a doc, so that it may carry dates.
#
# Each entry is one line of five fields joined by " | ": the test, the date
# it was first seen failing, the date it was last seen failing, how to run
# it alone, and its cause, or "unknown". A line leaves the record in the
# commit that fixes its cause. Run a Go test of it alone under the memory cap
# of the race target's machine; a count of runs and how many failed goes
# into the cause field when one is measured.
#
